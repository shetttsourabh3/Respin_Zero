# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:
- Be respectful and patient. Many users are new to PCB design; there are no stupid questions.
- Give feedback on the work, not the person.
- No harassment, insults or discrimination of any kind.

Report unacceptable behaviour to the maintainer through GitHub (private message or a private security advisory). Reports are handled in confidence. The maintainer may remove comments, issues or contributions that do not follow this code.
